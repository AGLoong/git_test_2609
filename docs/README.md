# Docs

项目文档目录，包含论文、报告和相关说明文档。

## 目录结构

```
docs/
├── paper/          # 论文草稿与最终版
├── figures/        # 论文插图（原始图 + 导出图）
└── references/     # 参考文献 BibTeX 文件
```

## 建议内容

- `paper/draft.md` — 论文初稿
- `paper/outline.md` — 论文大纲
- `figures/architecture.pdf` — 模型架构图
- `references/bibliography.bib` — 参考文献库
